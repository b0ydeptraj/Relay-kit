Relay-kit · Theme gallery

One token architecture, many identities.

The same app screen, rendered through six domain themes. Each theme is a preset in themes/ — a palette, a font pairing, a shape scale, a surface style and a density. relay-kit's own product stays on Relay Editorial; the apps you build with it pick the theme that fits their field.

Add a domain: copy a preset in themes/, change the palette + fonts + shape, and render it with mock/render_themes.py. Same components, new identity.
