usage: relay-kit context search [-h] --query QUERY [--limit LIMIT]
                                [--index-file INDEX_FILE]
                                [--embedding-model EMBEDDING_MODEL] [--json]
                                [project_path]

positional arguments:
  project_path          Project root to inspect

options:
  -h, --help            show this help message and exit
  --query QUERY         Query text
  --limit LIMIT         Maximum result count
  --index-file INDEX_FILE
                        Optional context index JSON path
  --embedding-model EMBEDDING_MODEL
                        Force Tier 1/2 embedding model (e.g., nomic-embed-
                        text-v1.5, bge-m3)
  --json                Emit machine-readable search results
